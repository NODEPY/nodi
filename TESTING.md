# Перевірка Nodi 0.2

Виконано в Linux amd64 з Go 1.23.2:

- `go test -race ./...` — пройдено.
- `go vet ./...` — пройдено.
- Збірка Go-ядра для Linux amd64 — пройдена.
- Перехресна збірка Go-ядра для macOS ARM64 — пройдена.
- `python3 scripts/check-core.py` — пройдено: передача 1 MiB через два процеси,
  ім'я UTF-8, побайтовий збіг, JSON-події, код через stdin, відмова при перезаписі,
  некоректний код, SIGTERM під час передачі та очищення тимчасового файлу.
- `bash -n scripts/run-macos.sh` — пройдено.
- `Info.plist` — XML/plist успішно прочитано.
- `Nodi.swift` — граматичний розбір tree-sitter-swift без синтаксичних помилок.
  Це НЕ компіляція й НЕ перевірка відповідності AppKit API.

Збережені тести ядра покривають порожній файл, UTF-8, бінарний файл,
неправильний токен і TLS-відбиток, наявний файл та symlink, небезпечні імена,
завеликий розмір, неправильний SHA-256, обрив і завеликий заголовок.

## Ще не перевірено

У цьому середовищі немає macOS та Apple SDK, тому Swift/AppKit-застосунок
ще не скомпільований і не запущений на Mac. Не перевірені його зовнішній вигляд,
системні дозволи, локальний підпис та поведінка Finder. Скрипт збере його на Mac.
Go-ядро попередньої версії вже було успішно запущено користувачем на Mac;
це не є перевіркою нового інтерфейсу.

Ручна перевірка на Mac:

1. Збірка через `bash scripts/run-macos.sh`, відкриття вікна.
2. Приймання → вибір файлу → тест на цьому Mac → відкриття отриманого файлу.
3. Повтор тієї самої передачі: зрозуміла помилка, старий файл збережено.
4. Некоректний код: помилка, кнопки знову доступні.
5. Зміна папки при вимкненому прийманні.
6. Зупинка приймання й повторний запуск: новий код працює.
7. Скасування великої передачі, завершення застосунку під час роботи.
8. Світла/темна тема, довге ім'я файлу, масштабування вікна.

Реальний Wi-Fi між пристроями, Android, файли 2 GiB, повний диск та незалежний
аудит безпеки ще не перевірені.
