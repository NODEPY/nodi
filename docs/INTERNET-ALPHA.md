# Інтернет у приватній альфі Nodi

Nodi спочатку пробує пряме з’єднання. Якщо TCP-з’єднання недоступне,
автоматично використовує Cloudflare relay. Адресу чи VPN вводити не потрібно.
Сервер пересилає зашифрований потік; перевірка TLS-сертифіката й токена
спареного пристрою залишається на клієнтах. Помилка TLS не запускає повторне
надсилання іншим маршрутом.

## Перше ввімкнення

1. Онови Nodi на обох пристроях. Збережи наявні дані застосунків і спарення.
2. Якщо пристрої ще не спарені, спаруй їх через QR або Wi-Fi.
3. На Mac натисни **Інтернет** та встав виданий для Mac код активації.
4. На Android натисни **Інтернет** та відскануй QR активації або встав код Android.
5. Увімкни приймання на обох пристроях. Дочекайся «Інтернет увімкнено».
6. Вибери вже спарений пристрій і надішли файл або текст.

Код прив’язаний до ідентичності конкретного пристрою. Це секрет доступу:
не публікуй його чи QR. Android зберігає його зашифрованим ключем AndroidKeyStore,
Mac — у Keychain. ADMIN_TOKEN не входить до застосунків.

Для цього локального комплекту оператор уже створив коди в ігнорованій папці
`build/internet-activation`: `mac.txt`, `android.txt`, `android-qr.png`.
Їх немає в Git чи APK. Файли доступні лише власнику.

## Обмеження й перевірка

- Це приватна альфа з активацією оператором, без загальнодоступної реєстрації.
- Через relay файл має бути не більший за 16 MiB. Локальний ліміт не змінюється.
- Приймання має працювати; опитування сервера кожні 10 секунд додає затримку.
- Сервер обмежує сесію десятьма хвилинами. Відновлення перерваного файлу немає.
- «Вимкнути» видаляє локальну активацію. Для серверного відкликання ключа
  оператор використовує адміністративний API.

Ручний тест: Mac на Wi-Fi, Android на мобільних даних. Надіслати текст і файл
в обидва боки; перевірити вміст. Перезапустити застосунки й перевірити збереження
активації. Вимкнути приймання на одному пристрої й перевірити зрозумілу помилку.
Повернути обидва в одну Wi-Fi мережу й перевірити локальну передачу.

Автоматичні JVM/Go перевірки не замінюють цей тест на фізичних пристроях:
AndroidKeyStore, Android TLS provider, дозволи Mac та фоновий режим потребують
окремої перевірки.
